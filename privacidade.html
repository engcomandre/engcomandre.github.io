1. Sobre este site

Este é o site pessoal de André Vieira da Silva, com informações profissionais e links para canais públicos. Esta política vale somente para este site, não para aplicativos ou serviços de terceiros.

2. Dados coletados

O site é estático. Não tem formulário, cadastro, conta de usuário nem banco de dados, e não usa cookies, rastreadores, análises ou publicidade. Todos os arquivos, inclusive as fontes, são servidos pelo próprio site, sem carregar recursos de terceiros.

O provedor de hospedagem pode registrar dados técnicos de acesso (como endereço IP, data, hora e navegador), conforme as políticas e obrigações legais dele.

3. Contato e seus direitos

Se você escrever para sgavsnake@gmail.com, o e-mail e as informações enviadas serão usados apenas para responder à sua mensagem. Para exercer direitos previstos na LGPD (acesso, correção ou exclusão), use esse mesmo endereço.

4. Links externos

O site tem links para LinkedIn, GitHub e repositórios públicos. Ao acessá-los, valem as políticas desses serviços.

5. Aplicativos

Cada aplicativo publicado por André Vieira terá política de privacidade própria, conforme os dados, permissões e bibliotecas que usar. Esta página não a substitui.

6. Atualizações

Esta política pode mudar. A versão vigente é sempre a publicada nesta página.
